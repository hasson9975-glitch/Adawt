# أدواتي — موقع أدوات عربية مجانية

موقع ثابت (HTML/CSS/JS) يعمل بالكامل داخل متصفح الزائر — لا يوجد خادم خلفي،
وملفات المستخدمين لا تغادر أجهزتهم أبداً.

## الأدوات (6)
1. ضغط الصور — `tools/compress.html`
2. تحويل صيغ الصور (PNG/JPG/WebP) — `tools/convert.html`
3. تغيير حجم الصور — `tools/resize.html`
4. عداد الكلمات والحروف — `tools/counter.html`
5. مولد كلمات المرور — `tools/password.html`
6. إزالة التشكيل من النص العربي — `tools/tashkeel.html`

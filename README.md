# أدواتي — موقع أدوات عربية مجانية

موقع ثابت (HTML/CSS/JS) يعمل بالكامل داخل متصفح الزائر — لا يوجد خادم خلفي،
وملفات المستخدمين لا تغادر أجهزتهم أبداً.

## الأدوات (6)
1. ضغط الصور — `tools/compress.html`
2. تحويل صيغ الصور (PNG/JPG/WebP) — `tools/convert.html`
3. تغيير حجم الصور — `tools/resize.html`
4. عداد الكلمات والحروف — `tools/counter.html`
5. مولد كلمات المرور — `tools/password.html`
6. إزالة التشكيل من النص العربي — `tools/tashkeel.html`

## النشر على GitHub Pages (مجاناً)
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub.
2. **مهم:** حساب GitHub المجاني يتطلب أن يكون المستودع **عاماً (Public)**
   ليعمل GitHub Pages. المستودعات الخاصة تحتاج خطة مدفوعة.
3. من صفحة المستودع: Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)` ← Save.
4. بعد دقائق يصبح الموقع متاحاً على: `https://USERNAME.github.io/REPO-NAME/`

## الربح من الإعلانات (Google AdSense)
1. سجّل في [Google AdSense](https://www.google.com/adsense/) وقدّم رابط موقعك بعد نشره.
2. بعد قبول حسابك ستحصل على كود إعلان — الصقه مكان كل تعليق في الملفات يقول:
   `<!-- مساحة إعلانية: الصق كود AdSense هنا بعد قبول حسابك -->`
   (ابحث عن class="ad-slot" في كل صفحة — هناك مساحتان في كل صفحة).
3. نصائح لقبول أسرع: محتوى عربي أصلي في كل صفحة (موجود)، صفحات كافية (7 صفحات)،
   وحركة زوار حقيقية. شارك الموقع في مجموعات مهتمة بالأدوات.

## ملاحظات تقنية
- الخط المستخدم: Tajawal من Google Fonts (عبر CDN).
- كل الأدوات تعمل بـ JavaScript خالص دون مكتبات خارجية (عدا الخط).
- كلمات المرور تُولّد عبر Web Crypto API الآمنة.

## صفحات قبول AdSense
أُضيفت 3 صفحات مطلوبة لقبول AdSense: `about.html` (من نحن)، `privacy.html` (سياسة الخصوصية)،
`contact.html` (اتصل بنا) — مع روابط لها في تذييل كل صفحة.
**تم:** استُبدل البريد المؤقت ببريد المالك في `contact.html`.
